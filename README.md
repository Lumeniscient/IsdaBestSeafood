# IsdaBestSeafood Point of Sales

IsdaBestSeafood is a java based Point of sales System (POS) for a seafood eatery that integrates Object-Oriented Programming and Java FXML Scene Builder. The system aims to provide a simple and efficient Point of Sale solution for IsdaBest Seafood vendor, enabling staff to manage seafood products, process customer orders, and maintain inventory. It supports two user roles(Admin, Cashier), where the Admin manages products, users, and sales reports, while the Cashier handles day-to-day transactions. 

# Implementation of CRUD
Create - add products, Orders, and transactions
Read - View/search records, prouduct list, and order/sales history
Update - Edit existing records
delete - Removes existing records
